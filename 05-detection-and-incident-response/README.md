# Detection and Incident Response

## Status
Starter folder — add a simulated alert triage or incident-handling exercise.

## Suggested project
**SOC Alert Triage and Incident Report**

Use fictional logs or an authorized training dataset. Document:
- Alert summary and severity rationale
- Relevant timestamps and event sequence
- Observable indicators
- Evidence supporting and contradicting the alert
- Whether the alert appears true positive, false positive, or inconclusive
- Containment, eradication, recovery, and follow-up recommendations as applicable

Use `../templates/incident-report.md` as a starting point. Do not invent log evidence or claim a simulated incident affected a real organization.
