# Security Hardening

## Status
Starter folder — add a hardening checklist and verification results from your own lab.

## Suggested project
**Baseline Hardening for a Test Linux System**

Document the test environment, chosen baseline or reference, changes made, and verification results. Possible topics include updates, account permissions, unnecessary services, firewall configuration, and logging.

For each recommendation, record:
- Why it matters
- Planned change
- Verification command or check
- Result
- Any operational trade-off

Only state that a control was implemented when you actually applied and verified it.
