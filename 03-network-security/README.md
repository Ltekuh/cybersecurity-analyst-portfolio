# Network Security and Traffic Analysis

## Status
Starter folder — add a packet-analysis lab you actually performed.

## Suggested project
**Network Traffic Analysis with Wireshark**

1. Use an authorized training capture or your own lab traffic.
2. Record the capture source and scope.
3. Apply relevant display filters and explain why you chose them.
4. Document observable facts such as protocol, source/destination, timestamps, and unusual patterns.
5. Explain alternative explanations and limits of the evidence.
6. Recommend defensive follow-up.

## Report checklist
- [ ] Lab environment and authorization
- [ ] Tools and version
- [ ] Filters or commands used
- [ ] Sanitized screenshots or small sample data
- [ ] Findings separated from hypotheses
- [ ] Defensive recommendations
- [ ] Limitations and references

Do not describe traffic as a confirmed DoS or SYN flood unless the evidence supports that conclusion.
