## Learning reflection

The most useful concepts I learned were the relationship between security controls and business risk, how to interpret alerts and event data, and how to structure a clear incident investigation. I practiced these ideas through lab exercises involving Linux permissions, SQL review, packet analysis, and alert triage, which helped me connect theory to practical security work. The biggest area I want to keep improving is operational decision-making: prioritizing what matters most in a live environment, documenting evidence clearly, and explaining how a control reduces a realistic risk. I also want to continue building confidence in Python scripting, threat modeling, and documenting findings for non-technical stakeholders.
