# Threat Modeling and Web Security

## Status
Starter folder — add a threat model or an authorized web security lab.

## Suggested project
**Threat Model for a Small Web Application**

Describe a fictional application, its users, important data, and trust boundaries. Identify plausible threats and map each to a mitigation.

A simple table can include:
- Component or asset
- Threat scenario
- Potential impact
- Existing or proposed control
- How the control could be verified

For web testing, use intentionally vulnerable training applications or systems for which you have explicit authorization. Document scope and avoid publishing exploitable details about real targets.
