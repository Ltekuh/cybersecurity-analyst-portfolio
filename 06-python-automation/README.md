# Python Security Automation

## Status
Starter folder — add a beginner-friendly script you tested.

## Suggested projects
- Validate a list of IP addresses or file names
- Parse a small, fictional log file and count event types
- Search sample records for repeated failed logins
- Calculate and display file hashes for files you are authorized to inspect

## Include
- What the script does and does not do
- Python version and how to run it
- A small sample input
- Expected output
- Test cases, including an invalid input
- Limitations and possible improvements

Keep the code readable. Do not include secrets, credentials, malware, or data collected without permission.
