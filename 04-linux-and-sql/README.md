# Linux and SQL Security Practice

## Status
Starter folder — add commands and queries you tested in a safe lab.

## Linux practice ideas
- Inspect file permissions with `ls -l` or `ls -la`
- Explain owner, group, and permission bits
- Review users and processes using appropriate commands in your lab
- Demonstrate least privilege with a safe example

## SQL practice ideas
- Use `SELECT`, `WHERE`, `ORDER BY`, `LIKE`, and `BETWEEN`
- Filter a fictional login or access-events table
- Explain what each query returns and what it cannot prove

## Documentation
Include the command/query, sample input, sanitized output, explanation, and one security lesson. Never publish real usernames, IPs, or log records that could identify a person or system.
